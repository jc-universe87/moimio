## 👋 Moimio란 무엇인가요?

교회 수련회, 청소년 캠프, 선교 대회, 가족 수련회를 한 번이라도 준비해 보셨다면 어떤 일인지 잘 아실 겁니다. 신청은 이메일로 들어오고, 방 배정표는 이 스프레드시트에, 소그룹 명단은 저 스프레드시트에 있습니다. 행사 직전 주말은 탭 사이로 이름을 옮겨 적으며 빠진 사람이 없기를 바라는 시간이 되곤 합니다.

**Moimio는 이런 스프레드시트 곡예를 끝내 줍니다.** Moimio는 무료 웹 앱으로 다음과 같은 일을 합니다.

1. 링크나 QR 코드로 공유하는 간단한 신청 양식으로 **등록을 받습니다**.
2. 클릭 한 번으로 **사람들을 방, 소그룹, 팀, 워크숍에 나눕니다**. 가족과 친구는 함께 두고, 남성 전용·여성 전용 방을 지키며, 여러분이 정한 규칙을 따릅니다.
3. **행사 당일까지 도와줍니다**. 인쇄용 명단과 서명지, 그리고 안내 데스크용 체크인 화면을 제공합니다.

Moimio를 *사용*하는 데 기술 지식은 필요 없습니다. 웹 양식을 작성하고 이름을 이 상자에서 저 상자로 끌어다 놓을 수 있다면 Moimio로 행사를 운영할 수 있습니다.

> **이름에 대하여.** *Moimio*는 한국어 **모임이오**, 곧 "모임입니다!"라는 말에서 왔습니다.

## 🙋 누구를 위한 앱인가요?

Moimio는 **자원봉사자가 운영하는 소규모·중간 규모 행사**, 보통 20명에서 수백 명 정도의 행사를 위해 만들어졌습니다.

| ⛪ 교회 | 🏕️ 캠프 및 수련회 | 🌍 선교 대회 | 👨‍👩‍👧 가족 및 청소년 수련회 |
|:---:|:---:|:---:|:---:|
| 외부 수련회, 소그룹 순환 | 캐빈, 숙소, 활동 그룹 | 대표단, 워크숍, 언어별 테이블 | 가족은 함께, 청소년은 골고루 |

기업용 티켓 판매 소프트웨어가 아닙니다. 결제 처리도, 마케팅 도구도 없습니다. **알맞은 사람을 알맞은 자리에 배정하는 일** 한 가지를 잘 해냅니다.

## ✨ 할 수 있는 일

| | |
|---|---|
| 📝 **나만의 신청 양식** | 전화번호, 생년월일, 소속 교회, 식이 요구 사항 등 원하는 질문을 고르세요. 링크나 QR 코드로 공유합니다. 가족 전체를 한 번에 등록할 수도 있습니다. |
| 👨‍👩‍👧 **가족과 친구는 함께** | 등록마다 짧은 **그룹 코드**가 주어집니다. 함께 있고 싶은 사람들이 같은 코드를 쓰면 Moimio가 같은 방이나 그룹에 배정합니다. |
| ✦ **클릭 한 번으로 배정** | **자동 배정**을 누르면 Moimio가 누가 어디로 갈지 제안합니다. 먼저 전체 제안을 확인한 뒤 확정하거나 취소하세요. 여러분이 결정하기 전에는 아무것도 바뀌지 않습니다. |
| 🏷️ **마크: 나만의 색상 라벨** | *리더*, *첫 참가자*, *찬양팀* 등 원하는 라벨을 붙이세요. 리더를 그룹마다 고르게 나누거나 찬양팀을 한데 모으도록 Moimio에 알려 줄 수 있습니다. |
| 🚻 **남성 전용·여성 전용 방** | 방마다 혼성, 남성 전용, 여성 전용을 지정하세요. Moimio는 이 규칙을 절대 어기지 않으며, 실수로 끌어다 놓아도 규칙이 깨지지 않습니다. |
| ✋ **결정은 여러분이** | 누구든 원하는 곳으로 끌어다 놓으세요. 배정이 끝난 방은 잠가서 엔진이 손대지 않게 할 수 있습니다. 방 배정에서는 제외하되 소그룹에는 남겨 둘 수도 있습니다. |
| 🖨️ **인쇄용 명단** | 출입구용 간단한 명단, 안내 데스크용 체크 칸이 있는 서명지, 팀용 상세 명단을 제공합니다. 여섯 가지 언어 중 원하는 언어로 인쇄하세요. |
| ✅ **태블릿이나 휴대폰으로 체크인** | 안내 데스크용 전체 화면 명단입니다. *결제*, *팔찌*, *동의서* 같은 체크 열을 직접 추가할 수 있습니다. |
| 👥 **팀과 함께** | 돕는 분들에게 필요한 만큼만 권한을 주세요. 읽기 전용, 체크인 전용, 전체 권한을 행사별로 지정할 수 있습니다. |
| 🔒 **개인정보 보호 기본 내장** | 클릭 한 번으로 본인 데이터를 내보내 주고, 사람을 깔끔하게 삭제하며, 신청 양식에 여러분의 개인정보 처리방침을 연결할 수 있습니다. |

## 🧭 사용 방법

모든 행사는 간단한 세 단계를 거칩니다. Moimio는 지금 어느 단계에 있는지, 다음에 무엇을 하면 되는지 알려 줍니다.

### 1 · 준비: *행사의 틀을 잡으세요*

행사 이름, 날짜, 장소를 정하세요. 신청 양식에 넣을 질문을 고르고, 방과 그룹을 만드세요. 체크리스트가 아직 빠진 것을 알려 줍니다.

## 🚀 시작하기

Moimio를 사용하는 방법은 두 가지입니다. **두 방법 모두 같은 기능을 가진 같은 앱입니다.**

<th width="50%">☁️ 호스팅 버전 사용</th>

</tr>
</table>

<details>
<summary><b>🛠️ Docker에 익숙한 분을 위한 빠른 설치</b></summary>
<br>

[Docker](https://docs.docker.com/get-docker/)와 Docker Compose가 설치된 기기가 필요합니다.

```bash
git clone https://github.com/jc-universe87/moimio.git
cd moimio
cp .env.example .env        # then change SECRET_KEY and POSTGRES_PASSWORD
docker compose up -d --build
```

**http://localhost:6120**을 열고 설정 화면에서 첫 관리자 계정을 만드세요.

| 서비스 | 주소 |
|---|---|
| Moimio(앱) | http://localhost:6120 |
| 백엔드 API | http://localhost:6121 |
| API 문서 | http://localhost:6121/docs |
| 상태 확인 | http://localhost:6121/health |

HTTPS, 이메일, 백업, 보안 강화는 [**빠른 설치 가이드**](docs/installation/quick-guide.ko.md)를 따르세요.

**업그레이드**는 프로젝트 폴더에서 명령 하나면 됩니다. 먼저 설정과 데이터베이스를 백업하고, 문제가 생기면 되돌리는 방법을 알려 줍니다.

```bash
./upgrade.sh           # update to the latest version on your branch
./upgrade.sh v1.0.6    # or move to a specific version (see CHANGELOG.md)
```

**컨테이너 이미지.** 각 릴리스는 `ghcr.io/jc-universe87/moimio-backend:<version>`와 `ghcr.io/jc-universe87/moimio-frontend:<version>`(예: `v1.0.6`)으로 게시됩니다. 항상 버전을 고정하세요. `:latest` 태그는 v1.0.6에 멈춰 있어 더 이상 갱신되지 않으며 지원되지 않습니다.

</details>

## 🌍 여러분의 언어로

앱 전체와 모든 인쇄용 명단을 여섯 가지 언어로 사용할 수 있습니다.

**English · Deutsch · 한국어 · Español · Português (Brasil) · Français**

팀원마다 자신의 언어를 고를 수 있고, PDF 언어는 따로 선택합니다. 독일어로 일하는 운영자가 국제 팀을 위해 영어 명단을 인쇄할 수도 있습니다. 새 언어를 추가하고 싶으신가요? [TRANSLATION_RULE.md](TRANSLATION_RULE.md)를 참고하세요.

## 🔒 데이터는 여러분의 것입니다

- **직접 호스팅하면 직접 소유합니다.** Moimio CE에서는 참가자 데이터가 여러분 서버의 데이터베이스에 저장됩니다. 제3자가 처리하지 않습니다.
- **여러분이 선택한 것만 밖으로 나갑니다.** 이메일은 이메일 계정을 설정했을 때만 발송되고, 웹훅은 직접 추가했을 때만 작동합니다.
- **개인정보보호(GDPR) 도구가 내장되어 있습니다**: 클릭 한 번으로 개인정보 내보내기, 수정, 확실한 삭제, 백업, 그리고 신청 양식에 개인정보 처리방침 링크를 제공합니다.

자세한 내용은 [GDPR 준수](docs/gdpr-compliance.md)에서 확인하세요.
