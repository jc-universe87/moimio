## 👋 What is Moimio?

If you've ever organised a church retreat, a youth camp, a mission conference or a family weekend, you know how it goes. Sign-ups arrive by email, the room list lives in one spreadsheet, the small groups in another, and the weekend before the event is spent copying names between tabs and hoping nobody gets left out.

**Moimio replaces that spreadsheet juggling.** It's a free web app that:

1. **Collects registrations** through a simple sign-up form you share as a link or QR code.
2. **Sorts people into rooms, small groups, teams or workshops** with one click, keeping families and friends together, respecting men-only and women-only rooms, and following the rules you set.
3. **Gets you through the event itself**: printable rosters and sign-in sheets, plus a check-in screen for the welcome desk.

You don't need to be technical to *use* Moimio. If you can fill in a web form and drag a name from one box to another, you can run an event with it.

> **The name.** *Moimio* comes from the Korean **모임이오**, "It is a gathering!"

---

## 🙋 Who is it for?

Moimio is made for **small and mid-sized events run by volunteers**, usually somewhere between 20 and a few hundred people:

| ⛪ Churches | 🏕️ Camps & retreats | 🌍 Mission conferences | 👨‍👩‍👧 Family & youth weekends |
|:---:|:---:|:---:|:---:|
| Weekends away, small-group rotations | Cabins, dorms, activity groups | Delegates, workshops, language tables | Keep families together, mix the teens |

It isn't enterprise ticketing software. There's no payment processing and no marketing tools. It does one job, **getting the right people into the right places**, and does it well.

## ✨ What you can do with it

| | |
|---|---|
| 📝 **Your own sign-up form** | Choose which questions to ask (phone, date of birth, church, dietary needs, anything you like). Share it as a link or QR code. People can register a whole family in one go. |
| 👨‍👩‍👧 **Families and friends stay together** | Each registration gets a short **group code**. People who want to be together share one code, and Moimio keeps them in the same room or group. |
| ✦ **One-click allocation** | Press **Auto-Allocate** and Moimio proposes who goes where. You see the whole proposal first, then accept it or throw it away. Nothing changes until you say so. |
| 🏷️ **Marks: your own colour labels** | Tag people as *Leader*, *First-timer*, *Worship team* or anything else. Tell Moimio to spread leaders evenly across groups, or keep the worship team together. |
| 🚻 **Men-only and women-only rooms** | Set each room to mixed, male only or female only. Moimio never breaks the rule, and neither can a stray drag-and-drop. |
| ✋ **You stay in charge** | Drag anyone anywhere. Lock a finished room so the engine leaves it alone. Keep someone out of the room draw but in their small group. |
| 🖨️ **Printable rosters** | Compact lists for the door, sign-in sheets with tick boxes for the welcome desk, detailed rosters for the team. Print them in any of the six languages. |
| ✅ **Check-in on a tablet or phone** | A full-screen list for the welcome desk. Add your own tick columns such as *Paid*, *Wristband* or *Consent form*. |
| 👥 **Bring your team** | Give helpers exactly the access they need: read-only, check-in only, or full access, event by event. |
| 🔒 **Privacy built in** | Hand anyone their own data with one click, remove people properly, and link your own privacy notice from the sign-up form. |

### 1 · Setup: *shape your event*

Give your event a name, dates and a place. Pick the questions for your sign-up form. Create your rooms and groups. A checklist tells you what's still missing.

## 🚀 Get started

There are two ways to use Moimio. **Both run the same app with the same features.**

<table>
<tr>
<th width="50%">☁️ Use the hosted version</th>
<th width="50%">🏠 Host it yourself (free)</th>
</tr>
<tr>
<td valign="top">

**Best if you just want to run an event.**

Sign up at **[moimio.app](https://moimio.app)** and start right away. No server and no installation, and updates are handled for you.

</td>
<td valign="top">

**Best if you want full control of your data.**

Install **Moimio CE** (Community Edition, this repository) on a small rented server, a spare computer or a mini-PC in the church office. It's free forever, and the data never leaves your machine.

👉 Start with the **[step-by-step Beginner Guide](docs/installation/beginner.md)**. It assumes no technical background and takes about two hours the first time.

</td>
</tr>
</table>

<details>
<summary><b>🛠️ Quick install for people comfortable with Docker</b></summary>
<br>

You need a machine with [Docker](https://docs.docker.com/get-docker/) and Docker Compose.

```bash
git clone https://github.com/jc-universe87/moimio.git
cd moimio
cp .env.example .env        # then change SECRET_KEY and POSTGRES_PASSWORD
docker compose up -d --build
```

Open **http://localhost:6120** and create the first admin account on the setup screen.

| Service | Address |
|---|---|
| Moimio (the app) | http://localhost:6120 |
| Backend API | http://localhost:6121 |
| API documentation | http://localhost:6121/docs |
| Health check | http://localhost:6121/health |

For HTTPS, email, backups and hardening, follow the **[Quick Install Guide](docs/installation/quick-guide.md)**.

**Upgrading** is one command from the project folder. It backs up your settings and database first and tells you how to roll back if anything goes wrong:

```bash
./upgrade.sh           # update to the latest version on your branch
./upgrade.sh v1.0.6    # or move to a specific version (see CHANGELOG.md)
```

**Container images.** Each release is published as `ghcr.io/jc-universe87/moimio-backend:<version>` and `ghcr.io/jc-universe87/moimio-frontend:<version>`, for example `v1.0.6`. Always pin a version. The `:latest` tag is frozen at v1.0.6, no longer moves, and is not supported.

</details>

## 🌍 Speaks your language

The whole app, and every printed roster, is available in six languages:

**English · Deutsch · 한국어 · Español · Português (Brasil) · Français**

Each team member picks their own language, and the PDF language is chosen separately. A German organiser can print an English roster for an international team. Want to add a language? See [TRANSLATION_RULE.md](TRANSLATION_RULE.md).

---

## 🔒 Your data stays yours

- **Self-hosted means self-owned.** With Moimio CE, participant data lives in a database on your server. No third party processes it.
- **Only what you choose leaves.** Emails go out only if you set up an email account, and webhooks only fire if you add one.
- **GDPR tools are built in**: one-click personal data export, editing, proper removal, backups, and a link to your own privacy notice on the sign-up form.

Read more in [GDPR Compliance](docs/gdpr-compliance.md).
