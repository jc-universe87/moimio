# 사용 설명서

이 설명서는 Moimio로 행사를 처음부터 끝까지 운영하는 방법을 설명합니다. Moimio를 이미 설치하고 로그인했다고 가정합니다. 아직이라면 [설치 가이드](../installation/README.ko.md)부터 시작하세요.

> 이 설명서는 오픈 소스로 직접 설치할 수 있는 **Moimio CE**(Community Edition)를 다룹니다. [moimio.app](https://moimio.app)의 호스팅 서비스에서도 같은 흐름이 적용됩니다. 두 에디션은 같은 코드를 사용합니다.

---

## 이 설명서를 읽는 방법

처음부터 끝까지 다 읽을 필요는 없습니다. 두 가지 경로를 추천합니다.

### → 내일 당장 행사를 운영해야 한다면

**[빠른 가이드](quick-guide.ko.md)**(약 10분)를 읽으세요. 행사 하나를 만들기부터 PDF 내보내기까지 따라가며, 세부 사항과 예외 상황은 건너뜁니다. 행사를 운영하기에 충분한 내용을 알게 됩니다.

### → 제품 전체를 이해하고 싶다면

번호가 붙은 장을 순서대로 읽으세요. 장마다 한 가지 기능 영역을 다룹니다. 모두 합쳐 30분 정도 걸립니다.

## 설명서 전체에서 쓰는 표기

- **굵은 글씨**는 클릭할 수 있는 화면 요소(버튼, 탭, 메뉴 항목)를 가리킵니다.
- `고정폭` 글씨는 값, 설정 키, 기술 개념을 가리킵니다.
- ▸ 표시는 클릭 순서를 나타냅니다. 예: **사용자 ▸ + 새 사용자 ▸ 사용자 생성**.
- 화면 구성을 익히는 데 도움이 되는 곳에는 스크린샷을 넣었습니다. 화면이 단순하거나 자주 바뀌는 곳은 글로 설명합니다. 시간이 지나면서 스크린샷이 현재 버전과 조금 다를 수 있습니다.
