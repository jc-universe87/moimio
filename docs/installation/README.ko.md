# 설치

이 가이드는 오픈 소스로 직접 설치할 수 있는 **Moimio CE**(Community Edition)의 설치 방법을 다룹니다(호스팅 서비스를 쓰려면 [moimio.app](https://moimio.app)에서 가입하세요. 설치가 필요 없습니다).

Moimio CE는 Docker Compose로 관리하는 Docker 컨테이너 세 개(백엔드, 프런트엔드, 데이터베이스)로 실행됩니다. 설치 과정은 대부분 이렇습니다. 저장소를 내려받고(clone), 설정하고, `docker compose up --build`를 실행한 뒤(여러분의 기기에서 소스 코드로 Moimio 이미지를 빌드합니다), 화면의 설정 단계에서 첫 관리자를 만듭니다.

이 폴더에는 배경 지식에 따라 고를 수 있는 가이드가 두 개 있습니다. 하나를 고르세요.

---

## 어떤 가이드를 따라야 하나요?

### → [빠른 설치 가이드](quick-guide.ko.md)

다음을 이미 알고 있다면 이 가이드를 쓰세요.

- Docker가 무엇이고 `docker compose` 명령을 어떻게 실행하는지.
- 서버에 SSH로 접속하고, 파일을 수정하고, 로그를 읽는 방법.
- TLS를 처리하는 리버스 프록시(Caddy, Nginx, Traefik, 또는 Cloudflare Tunnel)를 설정하는 방법.

걸리는 시간: 저장소를 내려받고 관리자로 로그인하기까지 **30~60분**.

### → [초보자 가이드](beginner.ko.md)

위 내용 중 하나라도 낯설다면 이 가이드를 쓰세요. 초보자 가이드는 다음을 다룹니다.

- **두 가지 주요 호스팅 방법**을 안내합니다. 임대한 VPS(클라우드 서버), 또는 집이나 사무실의 내 컴퓨터/미니 PC와 외부 접속용 Cloudflare Tunnel입니다.
- 키 생성부터 시작해 SSH 사용법을 처음부터 알려 줍니다.
- 아무것도 전제하지 않고 공식 한 줄 명령으로 Docker를 설치합니다.
- Moimio를 단계별로 설정하며, 각 부분이 무엇을 위한 것인지 설명합니다.
- 도메인 이름과 Caddy 또는 Cloudflare를 통한 HTTPS를 다룹니다.

걸리는 시간: 처음에는 **약 2시간**이며, 대부분 기다리는 시간입니다.

개발자가 아니어도 따라 할 수 있습니다. 명령을 꼼꼼히 복사하고, 잘 안 될 때 도움을 청할 마음만 있으면 됩니다.

## 비용

호스팅 비용은 어디에 설치하느냐에 따라 완전히 달라집니다.

| 위치 | 비용 | 적합한 경우 |
|---|---|---|
| 내 노트북 / 데스크톱(시험용) | 무료 | Moimio를 시험해 보고 사용 흐름을 익힐 때. 노트북을 계속 켜 두어야 하므로 실제 행사에는 맞지 않습니다. |
| 사무실에 둔 교회 소유 미니 PC | 하드웨어 1회 구입(€150~300) | 1년에 행사를 몇 번 여는 작은 교회. 사무실 전원과 인터넷이 안정적이라면 잘 작동합니다. |
| 클라우드 업체에서 임대한 VPS | 월 약 €4~10 | 대부분의 사용자. 항상 켜져 있고 쉽게 확장할 수 있습니다. 개인정보보호(GDPR)를 중시하는 주최자를 위한 EU 호스팅 옵션도 있습니다. |

실제 등록 링크에 쓸 **도메인 이름**(연 €10~15)도 있으면 좋습니다. 초보자 가이드에서 안내합니다.

## 하드웨어 요구 사항

Moimio는 가볍습니다. 대략적인 수치는 다음과 같습니다.

- **CPU:** 최신 x86_64 또는 ARM64 프로세서라면 무엇이든 됩니다. 2코어면 충분합니다.
- **RAM:** **최소 2 GB**, 4 GB면 여유롭습니다. 동시 등록 접속이 늘어도 메모리 사용량은 완만하게 늘어납니다.
- **디스크:** 앱 이미지와 데이터베이스에 **5 GB**. 데이터베이스는 천천히 커집니다(Moimio는 업로드 파일을 저장하지 않습니다).
- **네트워크:** 참가자가 등록 양식에 접속하려면 공인 IP(또는 Cloudflare Tunnel 같은 터널)가 필요합니다. 들어오는 포트 80/443(테스트용으로 TLS를 건너뛴다면 6120). 실제 행사에는 HTTPS를 계획하세요. 일부 앱 기능(오프라인 캐시, "새 버전이 있습니다" 안내)은 HTTPS나 `localhost`에서만 작동합니다.

고려 중인 기기가 요구 사항을 충족하는지 확인하는 방법:

- **CPU와 아키텍처:** `uname -m`(Linux/macOS), 또는 Windows의 "내 PC 정보"에서 "시스템 종류". `x86_64`, `aarch64`, `arm64` 중 하나가 나오면 괜찮습니다.
- **RAM:** `free -h`(Linux), 활성 상태 보기(macOS), 작업 관리자 → 성능(Windows).
- **남은 디스크 공간:** `df -h`(Linux/macOS), 파일 탐색기 → 내 PC(Windows).
- **외부 접속 가능 여부:** VPS라면 업체가 공인 IP를 알려 줍니다. 내 컴퓨터라면 초보자 가이드의 Cloudflare Tunnel 부분을 참고하세요.

2 vCPU와 2 GB RAM의 작은 VPS(유럽 업체에서 보통 월 €4~5 정도)면 150명 규모 행사를 무리 없이 처리합니다. **Raspberry Pi 4**(4 GB)도 교회 사무실에서 운영하는 작은 행사에 쓸 수 있습니다. 둘 다 예시일 뿐이며, Moimio는 특정 하드웨어나 호스팅 업체를 요구하지 않습니다.

## 운영 체제

Docker가 실행되는 곳이면 어디든 됩니다.

- **Linux**(Ubuntu 22.04+, Debian 12+, Fedora, Arch, ...): 실제 운영에 권장합니다.
- Docker Desktop을 쓰는 **macOS**: 개발용으로는 괜찮지만 실제 등록을 받는 행사에는 권장하지 않습니다(노트북은 서버가 아닙니다).
- Docker Desktop과 WSL2를 쓰는 **Windows**: 같은 이유로 주의가 필요합니다.

## 설치한 뒤

Moimio가 실행되면 브라우저에 자동으로 **초기 설정** 화면이 나옵니다. 성명, 이메일, 비밀번호(두 번)를 입력하고 **최고 관리자 생성**을 클릭한 뒤, 방금 만든 계정으로 로그인하세요. 아직 행사가 없으므로 **첫 행사 만들기** 버튼이 있는 **Moimio에 오신 것을 환영합니다** 화면이 보입니다.

일찍 해 두면 좋은 일 두 가지:

- **개인정보 처리방침 링크를 설정하세요.** 최고 관리자로 사이드바의 **워크스페이스**를 열고 단체의 개인정보 처리방침 웹 주소를 입력하세요. 그러면 공개 등록 양식의 동의 문장 바로 뒤에 링크가 걸립니다.
- **업그레이드와 백업을 계획하세요.** 두 가이드 모두 각각에 대한 짧은 섹션이 있습니다. 요약하면, `./upgrade.sh`는 git으로 설치한 Moimio를 업그레이드하며 먼저 데이터베이스를 백업합니다. 앱의 **백업** 페이지에서는 행사별 백업을 다운로드합니다.

호스팅 서비스나 다른 서버에서 옮겨 오시나요? [직접 운영하는 Moimio로 워크스페이스 옮기기(영문)](../moving-a-workspace.md)를 참고하세요.

그다음에는 [사용 설명서](../manual/README.ko.md)가 실제 행사 운영을 안내합니다. 행사 만들기, 등록 설정, 배정 엔진 실행, 체크인, 명단 내보내기까지 다룹니다.

설치 중 문제가 생기면 각 가이드 끝의 문제 해결 섹션에서 흔한 오류를 다룹니다. 그보다 이상한 문제라면 [버그를 신고하세요](https://github.com/jc-universe87/moimio/issues/new?template=bug_report.md).
