## 👋 O que é o Moimio?

Se você já organizou um retiro de igreja, um acampamento de jovens, uma conferência missionária ou um fim de semana em família, sabe como é. As inscrições chegam por e-mail, a lista de quartos fica em uma planilha, os grupos pequenos em outra, e o fim de semana antes do evento vai embora copiando nomes de uma aba para outra, torcendo para ninguém ficar de fora.

**O Moimio acaba com esse malabarismo de planilhas.** É um aplicativo web gratuito que:

1. **Recebe as inscrições** por meio de um formulário simples, que você compartilha como link ou QR code.
2. **Distribui as pessoas em quartos, grupos pequenos, equipes ou oficinas** com um clique, mantendo famílias e amigos juntos, respeitando quartos só para homens ou só para mulheres e seguindo as regras que você definir.
3. **Acompanha você durante o próprio evento**: listas e folhas de presença para imprimir, além de uma tela de check-in para a recepção.

Você não precisa entender de tecnologia para *usar* o Moimio. Se você sabe preencher um formulário na internet e arrastar um nome de uma caixa para outra, consegue organizar um evento com ele.

> **O nome.** *Moimio* vem do coreano **모임이오**, "É um encontro!"

---

## 🙋 Para quem é?

O Moimio foi feito para **eventos pequenos e médios organizados por voluntários**, normalmente entre 20 e algumas centenas de pessoas:

| ⛪ Igrejas | 🏕️ Acampamentos e retiros | 🌍 Conferências missionárias | 👨‍👩‍👧 Fins de semana de famílias e jovens |
|:---:|:---:|:---:|:---:|
| Retiros de fim de semana, rodízio de grupos pequenos | Chalés, alojamentos, grupos de atividades | Delegados, oficinas, mesas por idioma | Famílias juntas, adolescentes misturados |

Não é um sistema corporativo de venda de ingressos. Não há processamento de pagamentos nem ferramentas de marketing. Ele faz uma coisa só, **colocar as pessoas certas nos lugares certos**, e faz isso bem.

## ✨ O que você pode fazer com ele

| | |
|---|---|
| 📝 **Seu próprio formulário de inscrição** | Escolha quais perguntas fazer (telefone, data de nascimento, igreja, restrições alimentares, o que quiser). Compartilhe como link ou QR code. É possível inscrever uma família inteira de uma vez. |
| 👨‍👩‍👧 **Famílias e amigos ficam juntos** | Cada inscrição recebe um **código de grupo** curto. Quem quer ficar junto usa o mesmo código, e o Moimio mantém essas pessoas no mesmo quarto ou grupo. |
| ✦ **Atribuição com um clique** | Clique em **Atribuir automaticamente** e o Moimio propõe quem vai para onde. Você vê a proposta inteira primeiro e depois a aceita ou descarta. Nada muda até você decidir. |
| 🏷️ **Marcações: suas próprias etiquetas coloridas** | Identifique pessoas como *Líder*, *Primeira vez*, *Equipe de louvor* ou o que quiser. Peça ao Moimio para distribuir os líderes por igual entre os grupos ou manter a equipe de louvor junta. |
| 🚻 **Quartos só para homens ou só para mulheres** | Defina cada quarto como misto, apenas homens ou apenas mulheres. O Moimio nunca quebra essa regra, e um arrastar e soltar descuidado também não. |
| ✋ **Quem manda é você** | Arraste qualquer pessoa para qualquer lugar. Trave um quarto pronto para que o motor não mexa nele. Deixe alguém fora da distribuição de quartos, mas dentro do seu grupo pequeno. |
| 🖨️ **Listas para imprimir** | Listas compactas para a porta, folhas de presença com caixas de seleção para a recepção, listas detalhadas para a equipe. Imprima em qualquer um dos seis idiomas. |
| ✅ **Check-in no tablet ou celular** | Uma lista em tela cheia para a recepção. Adicione suas próprias colunas de marcação, como *Pago*, *Pulseira* ou *Termo de consentimento*. |
| 👥 **Traga sua equipe** | Dê a cada ajudante exatamente o acesso de que precisa: somente leitura, apenas check-in ou acesso total, evento por evento. |
| 🔒 **Privacidade desde o início** | Entregue a qualquer pessoa os próprios dados com um clique, remova pessoas do jeito certo e vincule seu próprio aviso de privacidade no formulário de inscrição. |

## 🧭 Como funciona

Todo evento passa por três fases simples. O Moimio mostra em qual delas você está e o que fazer em seguida.

### 1 · Configuração: *dê forma ao seu evento*

Dê ao seu evento um nome, datas e um local. Escolha as perguntas do formulário de inscrição. Crie seus quartos e grupos. Uma lista de verificação mostra o que ainda falta.

## 🚀 Comece agora

Há duas formas de usar o Moimio. **As duas rodam o mesmo aplicativo, com os mesmos recursos.**

<table>
<tr>
<th width="50%">☁️ Use a versão hospedada</th>
<th width="50%">🏠 Hospede você mesmo (grátis)</th>
</tr>
<tr>
<td valign="top">

**Ideal se você só quer organizar um evento.**

Cadastre-se em **[moimio.app](https://moimio.app)** e comece na hora. Sem servidor, sem instalação, e as atualizações ficam por nossa conta.

</td>
<td valign="top">

**Ideal se você quer controle total dos seus dados.**

Instale o **Moimio CE** (Community Edition, este repositório) em um pequeno servidor alugado, em um computador que esteja sobrando ou em um mini-PC no escritório da igreja. É grátis para sempre, e os dados nunca saem da sua máquina.

👉 Comece pelo **[Guia para iniciantes, passo a passo](docs/installation/beginner.pt-BR.md)**. Ele não exige nenhum conhecimento técnico e leva cerca de duas horas na primeira vez.

</td>
</tr>
</table>

<details>
<summary><b>🛠️ Instalação rápida para quem já conhece Docker</b></summary>
<br>

Você precisa de uma máquina com [Docker](https://docs.docker.com/get-docker/) e Docker Compose.

```bash
git clone https://github.com/jc-universe87/moimio.git
cd moimio
cp .env.example .env        # depois altere SECRET_KEY e POSTGRES_PASSWORD
docker compose up -d --build
```

Abra **http://localhost:6120** e crie a primeira conta de administrador na tela de configuração.

| Serviço | Endereço |
|---|---|
| Moimio (o aplicativo) | http://localhost:6120 |
| API do backend | http://localhost:6121 |
| Documentação da API | http://localhost:6121/docs |
| Verificação de saúde | http://localhost:6121/health |

Para HTTPS, e-mail, backups e segurança reforçada, siga o **[Guia de instalação rápida](docs/installation/quick-guide.pt-BR.md)**.

**Atualizar** é um único comando na pasta do projeto. Ele faz backup das suas configurações e do banco de dados antes e explica como voltar atrás se algo der errado:

```bash
./upgrade.sh           # atualiza para a versão mais recente do seu branch
./upgrade.sh v1.0.6    # ou muda para uma versão específica (veja CHANGELOG.md)
```

**Imagens de contêiner.** Cada versão é publicada como `ghcr.io/jc-universe87/moimio-backend:<version>` e `ghcr.io/jc-universe87/moimio-frontend:<version>`, por exemplo `v1.0.6`. Sempre fixe uma versão. A tag `:latest` está congelada na v1.0.6, não é mais atualizada e não tem suporte.

</details>

## 🌍 Fala o seu idioma

O aplicativo inteiro, e cada lista impressa, está disponível em seis idiomas:

**English · Deutsch · 한국어 · Español · Português (Brasil) · Français**

Cada membro da equipe escolhe o próprio idioma, e o idioma do PDF é escolhido à parte. Um organizador alemão pode imprimir uma lista em inglês para uma equipe internacional. Quer adicionar um idioma? Veja [TRANSLATION_RULE.md](TRANSLATION_RULE.md) (em inglês).

## 🔒 Seus dados continuam seus

- **Hospedar por conta própria significa ser dono.** Com o Moimio CE, os dados dos participantes ficam em um banco de dados no seu servidor. Nenhum terceiro os processa.
- **Só sai o que você escolher.** E-mails só são enviados se você configurar uma conta de e-mail, e webhooks só disparam se você adicionar um.
- **Ferramentas para LGPD/GDPR já vêm incluídas**: exportação de dados pessoais com um clique, edição, remoção adequada, backups e um link para o seu próprio aviso de privacidade no formulário de inscrição.

Saiba mais em [Conformidade com o GDPR](docs/gdpr-compliance.md).
